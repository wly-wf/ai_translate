# 中文残留回归记录（2026-09-17）

## 复现

经用户明确授权，使用应用保存的 Agnes 配置和截图原文进行真实请求。未输出密钥、服务地址或原始供应商错误内容。

使用修改前的提示词，Agnes 2.5 Flash 三次请求中一次返回：

> I didn't want to折腾 your history over such a minor issue

这证实英文中夹带普通中文来自模型输出。Agnes 2.0 Flash 同轮一次成功、两次 HTTP 429；成功的那次未见残留，不能将限流算作翻译质量失败。

修改后的第一轮中，两种模型共四次成功返回，均未见中文残留，另两次请求失败。有限样本不代表提示词能保证模型永远不漏翻，因此增加本地结果校验。

最终代码再次实测：Agnes 2.5 Flash 三次均成功且无中文残留；Agnes 2.0 Flash 一次成功且无中文残留，另两次 HTTP 429。该轮测试因限流未整体通过。修改后两轮共八次成功返回，均未见中文残留。

## 修复策略

- 提示词要求翻译完整的句子、普通词语、口语、习语和引用正文，遇到难以直译的词用自然表达转述，并在返回前自查。
- 中文名称在英文中使用已有英文名称或拼音。中文目标译文不应用中文残留检测。
- 英文结果存在中文时，仅豁免原文中完整存在的反引号代码、HTTP(S) 网址和标识符形式的占位符；不接受模型凭空添加代码标记来隐藏漏翻。
- 检测失败后携带原文和草稿纠正一次。再次失败则返回明确错误，不展示不合格草稿，不循环重试。
- 正常结果无额外 API 调用，触发纠正最多增加一次请求及对应延迟和费用。检查不保证语义准确，也不覆盖所有语言的混写；未加反引号的中文代码可能需要先标记为代码。

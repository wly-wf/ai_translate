# 选中文本浮标设计

## 目标

在 Windows 11 上，用户用鼠标选中可复制文本后显示一个翻译浮标。点击浮标会翻译对应文本；浮标不会自动消失，只有用户点击其他位置时才隐藏。用户再次选中新文本时，浮标移动到新选区并替换待翻译文本。

## 范围

本阶段仅实现 Windows 桌面端的鼠标选区浮标。不包含 OCR、翻译历史、多翻译服务商或管理员权限窗口的兼容承诺。旧版 `Alt + T` 全局快捷键在当前版本暂不提供。

## 交互状态

| 触发事件 | 行为 |
| --- | --- |
| 鼠标左键拖选后抬起，且取得有效文本 | 显示浮标，保存文本和选区位置。 |
| 浮标已显示，完成新的有效拖选 | 更新保存文本，将同一浮标移动到新选区。 |
| 点击浮标 | 隐藏浮标，调用既有翻译流程，并显示翻译结果窗口。 |
| 鼠标点击其他位置，且未形成有效的新选区 | 隐藏浮标。 |
| 没有鼠标操作 | 持续显示浮标。 |

## 架构

### SelectionService

Rust 后台服务监听全局鼠标左键抬起事件。每次抬起后等待短暂去抖（120 ms），再对鼠标位置下的 UI 元素尝试 UI Automation：

1. 读取当前选中的文本和选区矩形。
2. 若 UI Automation 不支持或返回空选择，保存当前剪贴板数据对象，模拟 `Ctrl+C`，读取纯文本，并仅在剪贴板未被用户改变时恢复完整的原剪贴板内容。
3. 取得非空文本时发布 `SelectionDetected { text, anchor }`；否则发布 `SelectionCleared`。

文本长度沿用现有单次翻译 12,000 字符限制；超过时不显示浮标并记录可读错误。

### FloatingButtonWindow

创建一个独立 Tauri Webview 浮标窗口，配置为无边框、透明、置顶、不显示任务栏，启动时隐藏。前端根据窗口标签渲染小型翻译按钮，不与结果窗口共享页面状态。

浮标位置为选区最后一个可见矩形的右上角，并加入 8 px 偏移。服务根据当前显示器工作区夹紧坐标，避免按钮越出屏幕。

### 状态机

后台维护 `SelectionState`：

- `Hidden`
- `Visible { text, anchor, generation }`

每次鼠标抬起都生成新的 `generation`。检测到新文本时更新 `Visible`；没有新文本且点击目标不是浮标时转换为 `Hidden`。浮标点击时原子地读取已保存的 `text`，先隐藏浮标，再调用现有 `translate_and_display`。

这样在开始新一轮拖选时，即使浮标暂时覆盖旧位置，也会在左键抬起后被新选区更新，不会错误地永久消失。

## 错误与兼容性

- UI Automation 失败时使用剪贴板兜底；复制失败或无文本时静默隐藏浮标。
- 模拟输入受 Windows UIPI 限制，对管理员权限窗口不保证可用。
- UI Automation 返回多个矩形时使用最后一个可见矩形定位。
- 浮标或结果窗口创建失败时在日志中记录错误；当前版本不注册全局快捷键。

## 测试与验收

自动测试覆盖状态机：新选择替换旧选择、普通点击清除、浮标点击保留正确文本、过期 generation 不覆盖新状态。

手动测试矩阵：记事本、浏览器文本、跨行选区、屏幕边缘、新选区更新、空白点击隐藏、浮标点击翻译、剪贴板回退后的原内容保留。管理员权限窗口仅记录实际行为，不作为通过条件。

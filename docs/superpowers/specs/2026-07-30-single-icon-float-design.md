# 单一小浮标设计

## 目标

选中文本后，只显示一个小型、独立的圆形翻译浮标，不显示额外的外框、容器或留白。

## 视觉与交互

- 浮标窗口与可点击按钮均为 `24 × 24` 逻辑像素。
- 按钮是圆形，直接承载翻译图标；删除当前 `36 × 36` 的外层容器和其深色背景。
- 保留轻微阴影与悬停亮度变化，确保小尺寸下仍可发现和点击。
- 浮标的点击行为、显示/隐藏规则和移动规则保持不变。

## 实现边界

- 前端改为单个按钮元素，并将样式尺寸改为 24 像素。
- Rust 端的 `FLOAT_SIZE` 同步改为 24，确保窗口大小、位置钳制和点击命中区域一致。
- 更新或新增前端测试，验证浮标窗口仍只会触发一次选中文本翻译。

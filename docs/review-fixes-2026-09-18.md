# 审查问题修复说明

## 已修复

- 禁止 API 自动重定向，避免密钥和原文被转发到其他源或降级到 HTTP；本地模拟服务器回归测试覆盖 307 与虚拟 api-key。
- 连接测试必须解析到有效模型文本，不再将 200 HTML、错误 JSON、空 choices 当作成功。
- 自定义供应商创建与编辑分离。当前维持一个兼容接口槽：已有配置时打开编辑；后端原子检查存在性，不允许新增覆盖凭据。创建完成后启用接口，再发布创建事件。
- 自动保存串行执行，删除排在进行中的保存之后；后端保存/删除共享锁，普通编辑不能重建已经删除的自定义供应商。
- 普通保存不再触发页面跳转或重新填充草稿；模型只剩一个时阻止删除，并明确提示使用供应商开关停用。无效草稿显示未保存提示。
- 设置页原先不显示供应商操作 notice，导致保存/删除错误不可见；现已显示。
- 增量译文只更新结果，不打断快速输入、不重置用户折叠的卡片；最终 IPC 返回同样复用该更新逻辑。
- 一个供应商配置读取失败会生成该供应商错误结果，健康供应商继续翻译。
- 偏好保存失败恢复已确认值；文本代理字段 400 ms 防抖，连接测试前刷新待保存值。
- 托盘与设置共用偏好写入通路；持久化时不再占用供鼠标处理读取的偏好状态锁，避免旧托盘快照覆盖新设置。
- 统一前后端字号范围为 12–20，并夹紧旧配置；IPv6 本机 HTTP 地址校验补全。
- 恢复输入框和结果文本的默认右键菜单，支持系统复制/粘贴操作。

## 性能和资源

- 翻译新批次取消旧批次任务，包括排队等待的请求；共享 Semaphore 最多允许 4 个模型请求同时运行。已发往供应商的请求仍可能计费。
- 按代理配置和超时复用 HTTP Client，复用连接池；缓存只保留最近一组配置。
- 完整结果兜底轮询间隔由 150 ms 延长至 1500 ms，即轮询频率降为原来的十分之一；正常更新仍由事件即时推送，事件丢失时兜底发现结果的等待时间会变长。
- 悬浮按钮独立脚本/样式入口：约 1.47 kB JS、1.79 kB CSS，另加载共享 React/Tauri 运行时代码，不再加载设置页及其样式。
- 启动时划词关闭则不创建悬浮 WebView 和取词线程，首次开启时再初始化。运行中关闭划词会停止取词工作，已初始化的钩子仍保留。
- 添加 Windows 单实例保护，重复启动激活原窗口，避免重复钩子和剪贴板工作器。
- 剪贴板快照加入 16 MiB 总预算，检查全局内存、位图、调色板和元文件尺寸；超过预算或无法确定尺寸时放弃剪贴板兜底，不破坏原内容。

- 关于页版本读取 package.json；README 修正 Gemini/Claude 原生支持、复制方式和自定义接口限制的描述。
- 修正 Windows 本地模拟服务器继承非阻塞 socket 状态造成的测试不稳定。

本次没有启动真实付费翻译，也没有把源码优化等同于启动时间或常驻内存实测。仍需在 Windows 桌面验证：记事本/浏览器/PDF 划词、多屏 DPI、剪贴板图片与富文本、辅助取词进程超时、实际代理、自启动登录和重复启动行为。UIA 的隔离辅助进程与超时策略保留；是否进一步改成常驻进程应以延迟基线和兼容性验收为依据。

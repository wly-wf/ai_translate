# AI Translate

## 鼠标选中文本翻译

鼠标选中文本后，应用会显示一个悬浮的翻译按钮。取词优先使用 Windows UI Automation，并沿鼠标命中元素、父级元素和焦点元素查找真实文本控件；目标控件不提供 UIA 选区时，才临时模拟 `Ctrl + C` 读取文本。兜底前会保存原剪贴板，读取后仅在剪贴板未被其他程序再次修改时恢复，避免覆盖用户的新内容。代码编辑器、终端、与本次释放位置不匹配的旧选区，以及无法安全识别的高权限窗口均不会启用剪贴板兜底。

当前版本只实现文本取词，不包含截图 OCR；OCR 保留为未来覆盖画布、图片和远程桌面等不可访问文本场景的补充方向。

Windows 11 上的轻量级多模型翻译工具。使用 Tauri 2、Rust 与 React 构建。

## 已实现

- 鼠标选中文本后显示悬浮翻译按钮；新选区会移动并更新同一个按钮。
- 托盘图标右键菜单新增“划词翻译”开关，可随时切换；关闭后选中文本不再出现悬浮翻译按钮。
- 可在设置中同时启用 DeepSeek、Xiaomi MiMo、阿里云百炼、智谱开放平台、Moonshot、OpenAI、Google Gemini 或 Anthropic Claude；翻译时会并发请求所有启用模型，哪个模型先完成就先展示哪个结果。翻译请求对 DeepSeek、Xiaomi MiMo 和阿里云百炼发送关闭思考参数；其他接口使用供应商默认行为，不保证关闭思考。
- 无边框、置顶、可隐藏的翻译结果浮窗；可复制译文。
- 手动输入翻译，便于在未复制文本时使用。
- API Key 使用 Windows Credential Manager 保存，不写入项目文件或浏览器本地存储。

## 运行

```powershell
cd D:\AI\ai_project\ai_translate\translator
npm.cmd run tauri dev
```

首次打开后，点击右上角菜单，在“供应商”中保存 API Key、URL 和模型名称，再点击“加入翻译”。可以用相同方式启用多个模型；之后选中文本并点击悬浮翻译按钮，即可同时查看多个模型的译文，也可以从悬浮翻译窗口进入快速翻译并手动输入文本。

## 验证

